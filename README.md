# BBJOMS

B&B KnitFab Jobwork Management System.

## BBJOMS

A clean rebuild of the factory ERP and jobwork management platform.

## Technology

- Flutter
- Node.js
- Express
- PostgreSQL

## Architecture

BBJOMS is being rebuilt from scratch using clean separation between:

- Presentation
- Application
- Domain
- Infrastructure
- Database

## Modules

- Dashboard
- Parties
- Yarn
- Yarn Inventory
- Machines
- Job Orders
- Production
- Fabric
- Dispatch
- Reports
- Analytics
